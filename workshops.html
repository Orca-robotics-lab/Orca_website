2 DOF Robotic Arm

Students assemble and program a fully functional 2-axis robotic arm from scratch. They wire, calibrate, and control the arm by the end of the session. Students develop a complete understanding of forward and inverse kinematics, not just how to build it, but why it moves the way it does.

    — Students leave with
  • 01Complete understanding of forward and inverse kinematics
  • 02Experience building and programming a real physical robot system
  • 03Simulation skills to visualise and verify robot motion
  • 04Practical foundation for robotics coursework and projects

Available

AMR Development in ROS2

Students learn how to build and simulate a complete Autonomous Mobile Robot from the ground up using ROS 2, the industry-standard robotics framework. Starting with robot modeling in URDF, they create a simulation environment in Gazebo, integrate sensors, perform mapping and localization, and finally implement autonomous navigation using the same tools and workflows used in modern robotic systems.

Students gain hands-on experience with the complete robotics development pipeline used to build real-world autonomous robots.

    — Students leave with
  • 01A fully simulated mobile robot built from scratch using URDF, Gazebo, and ROS 2
  • 02Hands-on experience creating simulation environments and integrating robot sensors
  • 03Understanding of mapping (SLAM) and localization techniques used by autonomous robots
  • 04Practical experience implementing autonomous navigation, path planning, and obstacle avoidance
LevelAdvanced
Duration4 Days

Introduction to ROS2

ROS 2 is the industry-standard framework used to build professional robotic systems. In this workshop, students learn the core ROS 2 communication architecture by implementing publishers, subscribers, service clients, service servers, action clients, and action servers from scratch. Using Turtlesim to visualize robot behavior, students develop a deep understanding of how robot software components communicate, exchange data, execute tasks, and coordinate actions within a robotic system.

    — Students leave with
  • 01A fully configured ROS 2 development environment on their machine
  • 02Working publisher-subscriber, service, and action-based applications built from scratch
  • 03Practical experience using Turtlesim to understand and visualize ROS 2 concepts
  • 04A strong foundation in robot software architecture and inter-node communication
